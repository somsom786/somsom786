# somsom786

I build local-first software and simulations. My current projects explore Windows systems telemetry, review workflows for coding agents, and reproducible experiments.

| Project | What to look at |
| --- | --- |
| [PULSE](https://github.com/somsom786/pulse-windows-monitor) | A Rust and Tauri Windows monitor. Scan a folder, inspect which files occupy space, and review recorded system metrics. |
| [FORGE](https://github.com/somsom786/forge) | A desktop workspace for reviewing coding-agent changes. Follow a mission from an isolated Git worktree through approval, verification and merge. |
| [PRIMORDIAL Lab](https://primrdl.xyz/) | A browser-based Lenia lab. Generate four variants, compare them on a shared clock, and save one locally. |
| [Blackjack Simulator & PnL Lab](https://github.com/somsom786/blackjack-simulator) | A browser practice table and a standard-library Python simulation with fixed-seed CSV replay. |

The GitHub project READMEs include local run commands, evidence from exercised workflows, and current limitations.
